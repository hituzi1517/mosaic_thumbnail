チャンネルURL・@ハンドル・チャンネルID

画像を選ぶここにドラッグ＆ドロップもできます
初回設定 APIキー
  1. Google Cloud でプロジェクトを選び、YouTube Data API v3 を有効にします。
  2. 「認証情報」からAPIキーを作成します。キーのAPI制限で YouTube Data API v3 を選びます。
  3. キーのウェブサイト制限に このサイトのドメイン/* を追加し、上の欄にキーを貼り付けます。

キーはこのタブに入力している間だけ使い、リクエストをGoogleに直接送ります。
