ON-DEVICE PHOTO MOSAIC

写真だけで、写真を描く。

1枚の元写真を、カメラロールの写真やYouTubeサムネイルでモザイクアートに変換します。画像処理そのものはこのiPhone / iPad内で行います。

写真はアップロードしません。 カメラロールの写真はブラウザの一時メモリだけで扱い、ページを閉じれば破棄されます。
大量写真モード対応。 2000枚前後でも、一度に全画像を展開せず、順番に軽量サムネイルへ変換してから処理します。
YouTubeサムネ取得はAPIキーが必要です。 GitHub Pagesで使う場合は、Google CloudでYouTube Data API v3を有効化し、HTTPリファラ制限付きのAPIキーを作るのが安全です。

4. 作成

このアプリは外部ライブラリ・解析サービス・画像APIを使いません。例外として、YouTubeサムネイルの取得時だけ、YouTube Data APIへAPIリクエストを送ります。PWA本体のHTML/CSS/JavaScriptだけがオフライン用にキャッシュされ、選んだ写真やAPIキーはキャッシュしません。
